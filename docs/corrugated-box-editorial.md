## 技能逐项检查

- 原料角色：主体为纤维原纸，层间使用淀粉胶，油墨和封箱材料另作区分。
- 状态链：浆料、平纸卷、波浪芯纸、单面纸幅、三层板、扁平箱筒、成箱没有混称。
- 操作细节：说明碎浆、除杂、成网、压榨、烘干、压楞、两次粘合、分切压线、开槽和折箱。
- 设备形态：碎浆容器与搅动机构、移动成形网、烘缸、沟槽辊、热板与输送加载机构均落实到操作。
- 工艺条件：没有编造统一温度、胶量、厚度、配方或承重值。
- 使用现场：撑箱、封底、装物、衬垫和封顶连续说明，提醒潮湿影响。
- 效果边界：纸板边压与整箱抗压分开，实验破坏载荷不直接作长期堆码允许重量。
