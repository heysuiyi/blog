# 蜂窝煤与土炕配图说明

配图直接以 SVG 编写，未使用图像生成模型。SVG 本身是可编辑源文件，中文标注、形状和箭头均可独立修改。

- `src/assets/coal-kang/coal-stove-section.svg`：煤饼俯视与纵剖、带侧向排烟口煤炉的纵剖。表现贯穿孔、炉箅、灰室、炉衬、进气和烟气流向。煤饼孔数和燃烧颜色仅为示意，上部封闭空间通过侧向烟道连接室外烟囱。
- `src/assets/coal-kang/kang-section.svg`：灶连炕纵剖，兼用作封面。表现灶膛、锅、炕面、烟道和烟囱，区分烟气流动与热量传递。为阅读清晰，省略炕内支撑和复杂导流结构；不提供施工尺寸。

核对依据：

- [蜂窝煤成型机专利：模腔、冲头与冲针](https://patents.google.com/patent/CN2078225U/zh)
- [土炕结构与传热研究](https://www.sciencedirect.com/science/article/pii/S2214157X2100085X)
- [土炕蓄热性能研究](https://hub.hku.hk/handle/10722/58995)
- [CDC：燃烧设备及烟囱与一氧化碳](https://www.cdc.gov/carbon-monoxide/about/)

验图重点：空气从燃料下方进入；煤饼孔道贯通；炉顶烟气能连接到排烟口；炕内烟气通道连通烟囱；黄色热量箭头穿过炕面，但烟气箭头不进入室内。两幅图分别说明煤炉和灶连炕，不表示任何蜂窝煤炉都可以直接接炕。
