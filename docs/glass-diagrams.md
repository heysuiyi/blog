# 玻璃文章配图说明

制作方式：直接绘制可编辑 SVG 矢量图，未使用 AI 位图生成器。沿用现有认知系列的暖白背景、深色文字和剖面表达。高温玻璃采用橙色、成品采用浅蓝色以区分状态，颜色不代表实物。

- `src/assets/glass/material-to-cup.svg`：作为封面及原料章节配图，连接配合料、玻璃液、压制、退火后成品。不是完整设备流程图。
- `src/assets/glass/pressing-section.svg`：展示热玻璃填入冲头与模具之间的间隙，侧面形成杯壁，底部形成杯底，冲头退出留下空腔。省略模具温控、口部约束和脱模机构，采用直壁轮廓简化表示。
- `src/assets/glass/annealing-lehr.svg`：展示连续退火炉中的输送方向、均温松弛及降温关系。曲线无刻度，不提供操作参数。
